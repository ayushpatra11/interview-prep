# interview prep

Practice code from a few rounds of interviews I did in 2025-26. Mostly HubSpot and Cloudflare.

## what's here

```
js/          JS fundamentals I was brushing up on (execution context, closures, async, etc.)
dsa/         DSA practice - mix of Python and C++ depending on what the role needed
lld/         Low-level design sessions - rate limiters, load balancers, DNS resolvers, etc.
sysdesign/   Notes on system design topics I was studying
```

## timeline

**Aug-Sep 2025** - HubSpot prep. Frontend-heavy role so spent most of the time going back through JS internals and doing some C++ DSA on the side.

**Dec 2025 - Jan 2026** - Cloudflare Zero Trust team. They wanted Python so most of the DSA here is Python. Also did a bunch of LLD (rate limiters, load balancers) and started on system design.

**Feb - Mar 2026** - Cloudflare Network Platform team. Switched to C++ for this one. More networking-focused on the system design side (BGP, anycast, Linux networking stack).
